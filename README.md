# 机车重联控制系统（CC:Tweaked）

Minecraft **CC:Tweaked** 物理化列车（**Simurail** 物理转向架）重联控制系统：单脚本主机/从机合一，换向拉杆选角色；PID 闭环驾驶、重联编组、冒进防护、性能标定一体。

---

## 功能

- **主机/从机合一**：同一份 `startup.lua`，模式拉杆实时决定角色（0-4 前进主机 / 5-10 中立从机 / 11-15 后退主机）
- **全网安全**：同一协议组恰好 1 台主机，0 台或多台 → 全列切断牵引 + 紧急制动
- **统一 PID 闭环**：单控制器分正负输出驱动/制动，分段增益、死区、滑行窗口、抗积分饱和、输出斜坡，全部按实测 dt 缩放
- **Simurail 转向架 CC 外设驱动**：驱动 = `setMaxStress(±128)`（应力 = 动力网络消耗），制动 = `setBrakeStrengthOverride(0..1)`，换向 = 应力符号
- **冒进防护**：红石电平读前方红灯，按接近程度制动；贴脸电平触发 EB 锁存（须手柄 EB 确认缓解）；倒车/目视行车/从机豁免
- **目视行车**：运行时 `VisualDriving` 命令，限速 36 km/h 且允许越红灯
- **性能标定**：`Calibrate` 命令两步确认（EB 位待命 + N 位启动），自动测全列加减速，最小二乘拟合存 `calib.json`，为列控预留
- **重联通信**：rednet 广播 ~10Hz，从机跟随控制数据并按 `mu_config` 翻转方向；协议组间隔离
- **故障安全**：主控失联 1.5s / 发送者超时 2.5s / 外设调用失败，一律切牵引 + EB

## 依赖

- Minecraft 1.21.1 + NeoForge
- CC:Tweaked
- Create（轨道/动力学网络）
- Simurail（物理转向架，提供 CC 外设与闭塞探测）
- 物理化列车装配结构（Sable）

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `locos/startup.lua` | 控制程序（主机+从机合一） |
| `locos/config_locomodel.lua` | 本车配置（接线面 / PID / 标定 / 外设） |
| `locos/mu_config.lua` | 重联配置（协议名 + 其他车相对方向） |
| `locos/bogey_probe.lua` | 转向架外设独立诊断脚本 |
| `CONFIG_GUIDE.md` | 配置与部署指南（中文） |
| `系统工作原理.txt` | 系统工作原理综述（纯文本） |
| `tcc/` | 上位机线路数据服务（Node.js 零依赖，规划中用途） |

## 快速开始

1. 每台车 `label set <自己的名字>`（与 mu_config 的键对应）
2. 复制 `locos/` 三个文件到每台车
3. 每台车按自己视角改 `mu_config.lua`（协议组一致、others 列对方）和 `config_locomodel.lua`（接线面）
4. 接线：手柄（sideSetSpeed）、模式拉杆（sideReverse）、红灯（sideRedSignal）三个输入面 + 显示器 + 无线 modem；转向架外设有线网络可达；**变速箱接常亮红石供转速**
5. 想当主机的车拉杆扳到前进/后退，其余中立，开机即运行

## 操作速查

- 模式拉杆：0-4 前进主机 / 5-10 中立从机 / 11-15 后退主机
- RHI 手柄：0 EB 急停 / 1-9 B9..B1 直接制动 / 10 N 空档 / 11-12 K1-K2 降速 / 13 C 巡航 / 14-15 K3-K4 提速
- 运行时命令（终端输入回车）：`VisualDriving`（`vd`）目视行车；`Calibrate`（`calib`）标定（EB 位待命、N 位启动）；`help`
- 标定结果：本机 `calib.json`（加减速 m/s²，供列控制动曲线）

## 冒进防护规则

- 电平 >0：切断牵引 + 制动强度 = 电平/15（越近越猛）
- 电平 15（贴脸）：EB 锁存，全制动 + 设定归零，须手柄拉 EB（信号 0）确认
- 豁免：倒车（拉杆 11-15，完全不读红灯）、目视行车、从机（跟随主机广播）

## 规划中

- 列控：限速封顶 / 超速常用制动 / 超速 EB / 目标制动曲线 / 站停（基于 `tcc/` 线路数据与 `calib.json` 标定结果）
- 控制源角色化：`auto` 角色（全中立拉杆 + 列控主控），两端列控电脑 active/standby 与人工交接

- 所有脚本/配置必须**纯 ASCII**（CC:Tweaked 加载不了中文注释），文档放本地即可
