# 机车重联控制系统（CC:Tweaked + Create 物理化列车）

给 Minecraft 物理化列车做的一套**车载列控程序**：一台 CC:Tweaked 电脑驱动 Create 动力网络上的 Simurail 物理转向架，实现主机/从机合一的 PID 闭环驾驶、重联编组、冒进防护与性能标定。

- 单文件 `startup.lua`，主机/从机由模式拉杆决定，不用维护两套脚本
- 驱动/制动/换向**只走转向架 CC 外设**，没有红石回退通道
- 可选：驾驶台遥显、键盘手动驾驶台（带警惕键）、车门集控、线路数据上位机

> 部署与配置细节见 [`CONFIG_GUIDE.md`](CONFIG_GUIDE.md)；工作原理综述见 [`系统工作原理.txt`](系统工作原理.txt)。

---

## 特性

### 驾驶控制

| 能力 | 说明 |
| --- | --- |
| 统一 PID | 单控制器分正负输出驱动/制动，分段增益、死区、滑行窗口、抗积分饱和、输出斜坡，全部按实测 dt 缩放 |
| 档位系统 | 16 挡 RHI 映射（EB / B9-B1 / N / K1-K4 / C），K 档按 5·1 km/h/s 变速，与实际速度解耦 |
| 设定速度接管 | 从 EB/B/C 拨回 N-K 区时，设定速度自动取**当前实际速度**，避免猛加猛减 |
| 目视行车 | `VisualDriving` 命令：限速 36 km/h 且允许越红灯 |

### 安全保护

| 能力 | 说明 |
| --- | --- |
| 全网安全 | 同一协议组**恰好 1 台主机**；0 台或多台 → 全列切牵引 + EB |
| 冒进防护 | 转向架探针读前方红灯的轨道距离，进入 4 格内 → **EB 锁存**（须手柄回 EB 确认缓解）；倒车/目视/从机豁免 |
| 过应力保护 | 可选 `Create_Stressometer`：应力超容量时压低驱动上限（宽回差 + 保持，避免自泵振荡） |
| 空转防护 | 可选，**默认关闭**：用标定曲线的加速度亏空反推打滑，只砍牵引绝不减制动 |
| 故障安全 | 主控失联 1.5 s / 发送者过期 2.5 s / 外设调用失败 → 切牵引 + EB |

### 重联与通信

- rednet 广播 ~10 Hz，从机跟随主机控制数据，按 `mu_config` 翻转方向；协议组之间天然隔离
- 三套协议互不干扰：控制 `<协议>`、遥显 `<协议>-disp`、手动台 `<协议>-manual`
- 车门集控（`door_ctrl.lua`）：每车一台独立电脑，`loco-door` 广播，左右门按重联朝向自动镜像

### 显示与手动台（都是可选）

- **驾驶台遥显**：`displayMode = true` 的电脑（显示器 + 无线 modem，无需转向架/传感器）接收主机快照，用**同一份绘制代码**画面板；断链显示 `STALE` / `LINK LOST`，不会静默显示过期数值
- **手动驾驶台**：遥显终端旁放一台 Simulated `linked_typewriter`，用键盘开车——`W/S` 拨档、`A/D` 岔口选边、`Shift` 拍 EB、`Space` 警惕键。模式由主机 `Manual` 命令控制并写盘持久化

### 标定与工具

- **性能标定**：`Calibrate` 两步确认（EB 待命 + N 启动），全牵引爬到顶速后按 50% 制动停车，拟合出速度相关曲线 `a(v)` / `d(v)`，存 `calib.json`（含每 2 m/s 采样表，供后续列控直接读）
- **mock 回归测试**：`tools/sim_display_test.py` 用嵌入式 Lua 5.1 把真脚本跑起来，覆盖显示/手动台/警惕/持久化共 50 项断言，无需进游戏
- **线路数据上位机**：`tcc/`（Node.js **零依赖**，手写 WebSocket + 静态服务，默认 8090 端口）

## 快速开始

1. **命名**：每台车 `label set <名字>`（与 `mu_config` 的键一致，大小写敏感）
2. **拷文件**：每台机车 `startup.lua` + `config_locomodel.lua` + `mu_config.lua`；车门电脑另放 `door_ctrl.lua`
3. **改配置**：`config_locomodel.lua` 按本车接线改面位；`mu_config.lua` 改协议名与其他车相对方向
4. **接线**：
   - 输入：手柄（`sideSetSpeed`）+ 模式拉杆（`sideReverse`）两个**模拟红石**面
   - 外设：显示器（可无）、无线 modem
   - 转向架：**必须贴面或同一有线网络可达**（没有红石回退，探针也走它）
   - 变速箱：**常亮红石**供转速，否则车不动
5. **开车**：想当主机的车拉杆扳到前进/后退，其余中立，开机即运行

## 档位速查（RHI 手柄 / 手动台档位，同一套 0-15 映射）

| 信号 | 档位 | 行为 |
| --- | --- | --- |
| 0 | **EB** | 全制动，设定速度归零（须回 EB 解除冒进锁存） |
| 1-9 | **B9…B1** | 直接制动，强度 `(10-sig)/15`：B9 = 60%，B1 ≈ 6.7% |
| 10 | **N** | 惰行，无牵引无制动，设定速度不变 |
| 11 / 12 | **K1 / K2** | 设定速度 −5 / −1 km/h 每秒 |
| 13 | **C** | 保持设定速度 |
| 14 / 15 | **K3 / K4** | 设定速度 +1 / +5 km/h 每秒 |

模式拉杆（`sideReverse`）：`0-4` 前进主机 / `5-10` 中立从机 / `11-15` 后退主机。

## 运行时命令

在运控车终端输入回车生效（大小写不敏感）：

| 命令 | 作用 |
| --- | --- |
| `VisualDriving` / `vd` | 开关目视行车（限速 + 允许越红灯） |
| `Calibrate` / `calib` | 性能标定：EB 位输入待命 → 拉到 N 位启动 |
| `Manual` / `man` | 开关手动驾驶台模式（会写 `manual.json` 持久化） |
| `help` | 列出命令 |

## 显示器读数

| 行 | 内容 |
| --- | --- |
| 1 | 本车 label（遥显终端为 `<主机 label>  CAB`） |
| 2 | `Set:` 设定速度 km/h |
| 3 | `Spd:` 实际速度 km/h（无速度传感器时 `N/A`） |
| 4 | `T:` 驱动应力，带符号表示方向 |
| 5 | `B:` 制动强度百分比 |
| 6 | `DIR:` 方向 |
| 7 | 状态标记 + 时钟（矮显示器时为 `时钟 标记`） |
| 8 | `M:` / `S:` + 档位，或 `** FAULT EB **` |
| 9 | 时钟（显示器高度 ≥ 9 时） |

第 7 行标记：`BRK` 制动中、`R:x` 前方红灯距离、`VIS` 目视行车、`LAT` 冒进锁存、`ARM` 标定待命、`SLIP:0.xx` 空转防护读数、`MAN` 手动模式、`VIG?` / `VIG!` 警惕警告 / 超时、`DSK<档><L/R>` 驾驶台请求。异常横幅：`STALE x.xs`（遥显过期）、`LINK LOST`（链路丢失）。

## 规划中

- **LKJ 列控**：限速封顶、超速常用制动/EB、目标制动曲线、站停（数据源：`tcc/` 线路数据 + `calib.json` 标定曲线）
- **道岔地面联锁**：`Simurail_TrackSwitch` 扳动 + 回读校验 + 进路锁表（外设无锁无占用查询，须自己实现）
- **编组解耦标定**：`calib.json` 目前与固定编组强绑定，是空转防护默认关闭的根因

## 注意

- **所有 `.lua` 与游戏内配置必须纯 ASCII**：CC:Tweaked 加载不了含中文的脚本，开机即报错。中文说明只写在仓库的 `.md` / `.txt` 里，不要复制进游戏电脑
- **没有红石输出回退**：驱动/制动/换向只走转向架外设，外设找不到时只打印错误并保持无输出
- 根目录的 `startup.lua` 是 `locos/startup.lua` 的**旧副本**（2026-10-13，不含过应力/空转防护与遥显），请勿用它部署
- `tools/ws_probe*.js` 是 `tcc/` 服务的探针脚本，需先启动 `node tcc/server.js`（默认 8090）
