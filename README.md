# 机车重联控制系统（CC:Tweaked）

Minecraft **CC:Tweaked** 物理化列车（**Simurail** 物理转向架）重联控制系统：单脚本主机/从机合一，换向拉杆选角色；PID 闭环驾驶、重联编组、冒进防护、性能标定一体。

---

## 功能

- **主机/从机合一**：同一份 `startup.lua`，模式拉杆实时决定角色（0-4 前进主机 / 5-10 中立从机 / 11-15 后退主机）
- **全网安全**：同一协议组恰好 1 台主机，0 台或多台 → 全列切断牵引 + 紧急制动
- **统一 PID 闭环**：单控制器分正负输出驱动/制动，分段增益、死区、滑行窗口、抗积分饱和、输出斜坡，全部按实测 dt 缩放
- **Simurail 转向架 CC 外设驱动**：驱动 = `setMaxStress(±128)`（应力 = 动力网络消耗），制动 = `setBrakeStrengthOverride(0..1)`，换向 = 应力符号
- **冒进防护**：转向架探针读前方红灯的**轨道距离**，红灯进入 4 格以内（视为已到信号机）直接 EB 锁存；不做接近减速，须手柄 EB 确认缓解；倒车/目视行车/从机豁免
- **目视行车**：运行时 `VisualDriving` 命令，限速 36 km/h 且允许越红灯
- **性能标定**：`Calibrate` 命令两步确认（EB 位待命 + N 位启动），全牵引爬到最高速度（牵引极限与 `maxSpeed` 取低者）后按 50% 制动力制动到停车；两段样本各拟合一条**速度相关曲线** `a(v)=a0+a1·v` / `d(v)=d0+d1·v`，连同采样表存 `calib.json`，供后续列控（限速、目标制动曲线、站停）使用
- **重联通信**：rednet 广播 ~10Hz，从机跟随控制数据并按 `mu_config` 翻转方向；协议组间隔离
- **车门集控**：独立 `door_ctrl.lua` 电脑（每车一台），左右门脉冲输入 / 常电平输出，rednet `loco-door` 广播，按重联朝向翻转左右侧，0.5s 状态心跳
- **故障安全**：主控失联 1.5s / 发送者超时 2.5s / 外设调用失败，一律切牵引 + EB

## 快速开始

1. 每台车 `label set <自己的名字>`（与 mu_config 的键对应）
2. 复制 `startup.lua` / `config_locomodel.lua` / `mu_config.lua` 到每台车；车门电脑另放 `door_ctrl.lua`
3. 每台车按自己视角改 `mu_config.lua`（协议组一致、others 列对方）和 `config_locomodel.lua`（接线面）
4. 接线：手柄（sideSetSpeed）、模式拉杆（sideReverse）**两个输入面** + 显示器 + 无线 modem；**转向架外设必须有线/贴面可达（没有红石回退通道）**；**变速箱接常亮红石供转速**（红灯不再接红石，改由转向架探针读取）
5. 想当主机的车拉杆扳到前进/后退，其余中立，开机即运行

## 操作速查

- 模式拉杆：0-4 前进主机 / 5-10 中立从机 / 11-15 后退主机
- RHI 手柄：0 EB 急停 / 1-9 B9..B1 直接制动 / 10 N 空档 / 11-12 K1-K2 降速 / 13 C 巡航 / 14-15 K3-K4 提速
- 从 EB / B9-B1 / C 拨回 N-K 区时，**设定速度自动取当前实际速度**（避免设定速度与实际速度差太大而猛加/猛减）；N-K 区内部换档不重置，K 档斜坡照常
- 运行时命令（终端输入回车）：`VisualDriving`（`vd`）目视行车；`Calibrate`（`calib`）标定（EB 位待命、N 位启动：全牵引到顶速 → 50% 制动到停）；`help`
- 标定结果：本机 `calib.json` v3——`accel.a0/a1/vmax`、`brake.d0/d1`（全制动曲线）、`brake.mps2`（50% 制动力实测值）、`topMps`、拟合质量 `rms/r2`、`profile`（每 2 m/s 采样表，给外部列控直接读）

## 冒进防护规则

- 数据源：**Simurail 转向架探针**（`getProbeOccupiedSignalDistance`），**固定读某一根轴**（`redProbeFront`，默认前端轴），返回前方最近"对本车红灯"的信号边界距离（格，沿轨道弧长）
- **不做接近减速**：列车按司机操作正常行驶，只有红灯进入 **4 格**以内（`redEbDistance`）时判定"已经到信号机了"→ **EB 锁存**（全制动 + 设定归零，须手柄拉 EB 确认）
- 4 格以外的红灯只在显示器上显示距离（`R:xx`），不干预驾驶
- 豁免：倒车（拉杆 11-15，固定轴朝车尾，保护方向错误）、目视行车、从机（跟随主机广播）
- 轴方向若与实际行驶方向相反（纹理方向标识容易看反），把 `redProbeFront` 取反即可；`bogey_probe.lua` 会打印两轴 `trackDir` 供核对

## 规划中

- LKJ 列控：限速封顶 / 超速常用制动 / 超速 EB / 目标制动曲线 / 站停（基于 `tcc/` 线路数据与 `calib.json` 标定结果）
- 控制源角色化：`auto` 角色（全中立拉杆 + 列控主控），两端列控电脑 active/standby 与人工交接

## 备注

- 所有脚本/配置必须**纯 ASCII**（CC:Tweaked 加载不了中文注释），文档放本地即可
- 控制器接线与 PID 参数按实车标定，详见 `CONFIG_GUIDE.md`
- 驱动/制动/换向只走转向架外设，**已无红石输出回退**；外设找不到时只打印错误并保持无输出
- 冒进防护读**转向架探针**，启动时会把 `redProbeWindow`（默认 128 格）写进每个转向架的探针距离；探针距离为 0 时模块不扫描、读数恒为 -1
- `tools/ws_probe*.js` 是上位机 `tcc/` 服务的探针脚本，该服务目前不在本目录中，单独运行会因缺少 `tcc/*.json` 失败
